Installation and Setup

Install XAMPP and Git.

Copy the project folder into the htdocs directory.

Start Apache and MySQL from the XAMPP Control Panel.

Open phpMyAdmin and create a database named graminrozgar.

Import the project's SQL file if one is available, or create the required database tables.

Configure the database connection in the project's database configuration file.

Open the project in your browser using:

http://localhost/GraminRozgar/

Project Purpose

The purpose of GraminRozgar is to make rural employment opportunities easier to access and to support transparent management of workers, jobs, work progress, and wages.
